# Unpowered Free-Hand Glider Project
This repository contains the computational scripts, analysis tools, and design code developed for the Unpowered Free-Hand Glider Project. 
This work was conducted as the Special Term 1st Aeronautical Stream Project within the Department of Mechanical Engineering, University of Moratuwa (Intake 2025 / 25th Batch).

## Authors & Contributors

Generative AI tools (including large language models) were utilized during the development of this repository for code scaffolding, debugging, optimization, and documentation assistance. All analytical formulations, aerodynamic parameters, geometry definitions, and outputs were manually reviewed, validated, and integrated by the authors.

## Project Overview
Stream:Aeronautical Engineering Specialization
Term:Special Term (1st Aeronautical Project)
Institution: Department of Mechanical Engineering, University of Moratuwa
Scope: Aerodynamic modeling, low-Reynolds flight considerations, geometry design, and performance analysis for an unpowered free-flight glider.

This repository is maintained for academic and project evaluation purposes.
